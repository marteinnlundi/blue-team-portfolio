# Contributing

This repo holds documentation and standards only.

## Rules

- Do not add application source code here.
- Keep docs short and testable.
- If you change schemas, update examples and reasoning.

## Writing standards

- Use clear headings and bullet points.
- Add examples when a field is easy to misunderstand.
- Prefer JSON examples that match the schema exactly.

## Pull requests

- One topic per PR.
- Link to an issue when relevant.
- CI must pass.
